编辑内容
2 - 60 个字符
置顶后展示在列表首位
提交前校验：必须是 https 且图片可访问
联动示例：「置顶」为「是」时，「置顶截止时间」字段动态出现；
「分类」选择「视频」时，出现「视频时长」字段（必填）。
—— 都由 schema 的 visibleWhen 配置驱动，不改组件代码。
对应的 Schema
// src/views/content/schema.ts export const contentFormSchema = [ { field: 'title', label: '标题', type: 'input', required: true, rules: [ { min: 2, max: 60, message: '2-60 个字符' } ] }, { field: 'category', label: '分类', type: 'select', required: true, options: [ { label: '图文', value: 'article' }, { label: '视频', value: 'video' } ] }, { field: 'publishAt', label: '发布时间', type: 'datetime', required: true }, { field: 'top', label: '置顶', type: 'switch', help: '置顶后展示在列表首位' }, { field: 'topUntil', label: '置顶截止时间', type: 'datetime', visibleWhen: 'top', // ← 联动 visibleValue: true }, { field: 'cover', label: '封面图 URL', type: 'input', required: true, rules: [ { pattern: /^https:\/\//, message: '必须是 https' } ] } ] as const
这个设计的价值
· 新增字段 = 改 schema，不动组件
· 3 个业务表单共用一套引擎
· 类型由 schema 推导，无 any
· 校验规则、联动显隐、布局全由配置决定
